치지직 스트리머, 매니저, 파트너 등의 배지 채팅을 놓치지 않게 한눈에 모아서 보여주는 브라우저 확장프로그램입니다.

채팅이 빠르게 흘러가는 라이브 방송에서 스트리머의 한마디, 매니저의 안내, 중요한 답변을 놓쳐본 적이 있으신가요?  
배지 모아 챗은 배지가 달린 채팅을 별도의 팝업창으로 모아 보여주어 방송에 집중하면서도 핵심 채팅을 한눈에 확인할 수 있게 해줍니다.

---

## 주요 기능

- **배지 채팅 모아보기**  
  스트리머, 매니저, 파트너 등 배지가 달린 사용자의 채팅을 자동으로 수집하여 별도 팝업창에 정리해 보여줍니다.

- **다시보기(VOD) 배지 채팅 모아보기**  
  다시보기(VOD) 시청 시에도 라이브 방송과 같이 배지 채팅을 띄워줍니다.

- **모아보기 대상 직접 추가**  
  배지가 없는 스트리머라도 닉네임을 등록하면 해당 스트리머의 채팅을 팝업창에서 함께 모아볼 수 있습니다. 현재 채널에만 적용되는 대상은 채널당 최대 200명, 모든 방문 채널에 공통으로 적용되는 대상은 최대 20명까지 등록할 수 있습니다. 모아보기 제외 목록도 현재 채널 / 모든 방문 채널 범위를 선택해 관리할 수 있습니다.

- **채팅창 배지 알림 효과**  
  채팅창에서 배지 사용자 또는 직접 추가한 스트리머가 채팅을 쳤을 때 시각적인 강조 효과로 빠르게 인지할 수 있습니다. 필요하지 않은 닉네임은 사용자가 직접 알림 대상에서 제외할 수 있습니다.

- **모아보기 제외 / 미활동 닉네임 자동 정리**  
  보고 싶지 않은 닉네임은 모아보기에서 제외하고, 활동이 없는 닉네임은 자동으로 정리해 목록을 깔끔하게 관리할 수 있습니다.

- **채널별 독립 설정**  
  채널마다 추가한 닉네임, 숨김 목록, 표시 옵션이 따로 저장되어 여러 스트리머를 시청해도 설정이 섞이지 않습니다.

- **세밀한 표시 커스터마이징**  
  설정창 라이트 / 다크 / 시스템 테마, 팝업창·채팅창 폰트 크기, 라이브·다시보기 채팅창 넓이, 팝업창·채팅창 배경색과 테두리, 팝업창 시간 표시, 채팅창 상단 배지 알림 효과를 원하는 방식으로 조정할 수 있습니다.

- **채팅창 요소 숨김**
  채팅창의 랭킹, 진행 중인 미션, 미션 메시지, 승부예측, 구독 메시지, 후원 메시지를 필요에 따라 숨길 수 있고, 팝업창에서는 방장·매니저·운영자·파트너 배지만 남기도록 설정할 수 있습니다.

- **채팅 보조 표시**
  채팅창에 채팅 시간을 표시하거나, 블라인드 / 클린봇 등으로 가려진 채팅을 원문으로 다시 표시할 수 있습니다.

- **채널 세션 캐시**  
  방송 중 새로고침하거나 페이지를 이동해도 모아둔 채팅을 유지할 수 있습니다. 브라우저를 닫으면 자동으로 정리되며, 채팅의 영구 저장은 제공하지 않습니다.

## 이런 분께 추천합니다

- 시청자가 많아 채팅이 빠르게 흘러가는 방송을 자주 보시는 분
- 스트리머의 답변이나 매니저의 안내 채팅을 놓치고 싶지 않은 분
- 파트너 스트리머나 주요 배지 스트리머의 참여 채팅을 모아 보고 싶은 분
- 관심 있는 스트리머의 채팅을 따로 확인하고 싶은 분

## 참고 사항

- 모아보기 대상과 제외 목록은 현재 채널에만 적용하거나 모든 방문 채널에 공통으로 적용하도록 범위를 선택할 수 있습니다.
- 채널 세션 캐시는 브라우저 세션 동안만 유지됩니다.
- 채팅의 영구 저장은 제공하지 않습니다.
- 치지직 페이지 구조가 변경될 경우 일부 기능이 일시적으로 정상 동작하지 않을 수 있습니다.

## 업데이트 방법

자동으로 업데이트가 되지 않는다면, 사용 중인 브라우저의 확장 프로그램 관리 페이지에 접속하여 상단의 **업데이트** 버튼을 클릭하세요.

- **Chrome**: `chrome://extensions/`
- **Edge**: `edge://extensions/`
- **Whale**: `whale://extensions/`
- **Firefox**: `about:addons` 페이지 상단 톱니바퀴 > 업데이트 확인

## 권한 안내

- **storage**: 사용자가 설정한 옵션과 채널별 닉네임 목록을 브라우저에 저장하고, 원본 스타일 표시를 위해 후원·구독·미션·구매 채팅의 원본 모양을 브라우저 세션 동안 임시로 보관하기 위해 사용합니다.
- **scripting / tabs**: 치지직 페이지 내부에 팝업창과 알림 효과를 표시하기 위해 사용합니다.
- **치지직 관련 도메인 접근 권한**: 치지직 채팅 화면에서 배지 정보를 확인하고 모아보기 기능을 제공하기 위해 사용합니다. (`chzzk.naver.com`, `api.chzzk.naver.com`, `comm-api.game.naver.com`)

본 확장 프로그램은 사용자의 설정과 데이터를 외부 서버로 전송하지 않으며, 필요한 정보는 사용자의 브라우저 안에 저장됩니다.

**[1.2.9 업데이트 내용]**

- 모아보기 팝업의 후원·구독·미션·구매 채팅을 치지직 원본 모양 그대로 표시하는 `후원·구독·미션·구매 원본 스타일 표시` 옵션을 추가했어요.
- 상품 구매(커머스) 알림 채팅도 배지 사용자나 직접 추가한 대상인 경우 모아보기 팝업에 함께 수집하도록 했어요.
- 모아보기 대상과 제외 목록에 `현재 채널` / `모든 방문 채널` 적용 범위를 선택하는 탭을 추가해, 모든 채널에 공통으로 적용할 대상도 등록할 수 있도록 개선했어요. (공통 대상은 최대 20명)

**[1.2.8 업데이트 내용]**

- 가려진 채팅 행의 클래스뿐 아니라 실제 블라인드 / 클린봇 안내 문구까지 확인한 뒤 원문을 복원하도록 판별 조건을 보정했어요.
- 복원할 원문이 없거나 복원 쓰기 한도를 소진한 채팅 행은 반복 처리하지 않아 불필요한 DOM 변경과 재시도를 줄였어요.
- 모아보기 팝업의 한줄 보기에서 구독권 선물 채팅의 닉네임과 유형 태그가 줄바꿈으로 어긋나지 않도록 배치를 보정했어요.
- 방장·매니저 배지 없이 파트너 배지만 있는 채팅은 배경, 테두리, 글자색을 초록색으로 구분하도록 개선했어요.

**[1.2.7 업데이트 내용]**

- 채팅 팝업이 Picture-in-Picture 등의 iframe으로 표시되는 환경에서도 배지 모아보기 버튼과 팝업창이 동작하도록 개선했어요.
- 설정창의 테마 버튼 왼쪽에 업데이트 배너 표시 버튼을 추가하고, 끄면 현재 배너를 닫고 이후 업데이트 배너도 표시하지 않도록 개선했어요.

**[1.2.6 업데이트 내용]**

- 치지직 내부 채팅 데이터가 이미 블라인드 또는 클린봇 안내 문구로 변경된 경우 이를 원문으로 잘못 복원하지 않도록 보정했어요.
- 같은 채팅 행이 반복해서 가림 문구로 되돌아오는 경우 복원 횟수를 제한해 React 재렌더와의 반복 처리 및 성능 저하를 방지했어요.

**[1.2.5 업데이트 내용]**

- 가려진 채팅이 처음 블라인드 또는 클린봇 처리되는 순간에도 캐시된 원문을 즉시 복원하도록 보정했어요.
- 채팅 DOM과 내부 데이터가 늦게 준비되는 경우 짧게 재시도하고, 페이지 진입 시 설정 전달이 누락되면 현재 설정을 다시 요청하도록 개선했어요.
- 채팅 원문이 문자열이 아닌 배열이나 객체 형태로 전달되는 경우에도 본문을 정상적으로 복원하도록 개선했어요.

**[1.2.4 업데이트 내용]**

- 치지직의 색상 변수 개편에 대응하고 자체 라이트 / 다크 폴백 색상을 추가해 모아보기 팝업과 프로필 카드의 색상이 안정적으로 표시되도록 개선했어요.
- 치지직의 새로운 채팅 닉네임, 배지, 인증 마크, 새 메시지 알림 클래스에서도 채팅창 폰트 크기 조절과 정렬이 동작하도록 보정했어요.
- 채팅창 폰트 크기를 조절해도 닉네임 프로필 다이얼로그는 기본 글자와 배지 크기, 간격을 유지하도록 개선했어요.
- 미션 등록, 결과, 거절 이벤트가 역할 배지 필터와 관계없이 모아보기 팝업에 수집되도록 보정했어요.
- 치지직의 `unload` 제한으로 발생하던 콘솔 경고를 없애고 세션 캐시 저장과 이벤트 정리를 `pagehide`에서 처리하도록 변경했어요.
- 채널이 확정되기 전에 들어온 채팅과 미션 이벤트는 잠시 보류했다가 현재 채널이 확인된 뒤 처리하도록 개선했어요.
- 세션 캐시 항목에 소속 채널을 기록하고 저장 / 복원 시 다른 채널 항목을 걸러내, 채널 전환 후 채팅이 섞이는 문제를 방지했어요.

**[1.2.3 업데이트 내용]**

- 치지직이 채팅 리스트를 새로 교체한 뒤에도 가려진 채팅 표시와 채팅 시간 표시가 계속 동작하도록 감시 로직을 보정했어요.
- 라이브 / 다시보기 임베디드 채팅에서도 가려진 채팅 원문 복원과 원복이 안정적으로 동작하도록 채팅 행 탐색 범위를 보정했어요.
- 가려진 채팅 처리 후 치지직 내부 원문 데이터가 비워지는 경우에도 미리 캐시한 원문으로 복원할 수 있도록 보정했어요.

- 가려진 채팅 표시와 채팅 시간 표시의 활성 상태를 페이지에 즉시 반영해 중복 처리 가능성을 줄였어요.

- 모아보기 팝업창의 필터 영역이 작은 높이에서도 보이도록 최소 높이와 펼침 / 접힘 후 높이 계산을 보정했어요.

- 채팅창 넓이 조절 시 닉네임 프로필 카드와 더보기 메뉴 팝오버가 조절된 채팅창 폭에 맞게 표시되도록 개선했어요.
- 모아보기 팝업창 항상 펼침 사용 중에는 고정핀과 닫기 버튼이 비활성화 상태로 보이도록 개선했어요.
- 채팅창 폰트 크기 조절 시 고정 메시지와 치지직 프로필 다이얼로그는 기본 폰트 크기를 유지하도록 적용 범위를 보정했어요.

- 분리된 치지직 채팅 팝업에서는 채팅창 넓이 조절을 적용하지 않고, 치지직 자체 폰트 설정과 겹치지 않도록 확대 설정은 100%까지만 적용되게 했어요.
- 채팅창 랭킹 숨김 사용 시 숨김 클래스가 반복적으로 제거 / 재적용되며 개발자도구에서 깜빡이던 문제를 줄였어요.
